# Diarium Pocket(スマホ用・for_me の入口)

iPhone で書いた **勉強時間・日記(気分・テーマ・本文・写真)・睡眠・出費/収入・タスク・メモへの追記** を OneDrive 経由で PC へ届け、
PC からは **直近7日の勉強時間・プロジェクトの次の項目・今日の予定・やること・最近の睡眠** を受け取って表示する小さな Web アプリ(PWA)です。

```
iPhone(Pocket) ──書く──▶ OneDrive「アプリ/Diarium Pocket/study」 ──▶ 予定表アプリ(Agenda)・ランチャーが確認なしで取り込む
               ──書く──▶ OneDrive「アプリ/Diarium Pocket/inbox」 ──▶ 日記アプリ(Diarium)が確認して取り込む
               ──書く──▶ OneDrive「アプリ/Diarium Pocket/tasks」 ──▶ カンバン(Opus)が確認して追加する
               ──書く──▶ OneDrive「アプリ/Diarium Pocket/memos」 ──▶ メモアプリ(Nota)が確認して末尾に追記する
iPhone(Pocket) ◀─読む── OneDrive「アプリ/Diarium Pocket/outbox」 ◀── ランチャー(Ianua)が起動時に書き出す
```

**勉強時間(2026-10-06)**: 「今日」タブのいちばん上。直近7日の合計と棒グラフ、+30〜+120分・自由入力・
今日/昨日、昨日が未報告なら「昨日は何分?」(1日1回)、「⏱ 15分だけ始める」で計測(開始時刻を端末に置き、差で数える。
閉じても狂わない。3時間以上続いていたら終わった時刻を聞く)。送った記録の控え(ID・日付・分だけ)を14日持ち、
PC の集計に入っていない分だけを数字に足す。その下に「プロジェクトの次の項目」(前線。見るだけ)。仕様は for_me/STUDY_TIME_PLAN.md。

- 書いた記録は、送るまで iPhone の中だけに保存されます(電波がなくても書けます)。写真は送る前にスマホの中で縮小します(長い辺 1600px)。
- 送り先・読み先は、あなたの OneDrive の「アプリ/Diarium Pocket」フォルダだけです(ほかのファイルは見えない権限)。
- 送り終えると、iPhone からは本文・写真を消します(「送った記録」には日付と種類だけ残ります)。
- PC では各アプリを開いたときにチェックボックスつきの一覧が出て、**選んだものだけ** が入ります。取り込んだファイルは PC 内の保管フォルダへ移り、OneDrive からは消えます。
  - 日記: 同じ日の日記が PC にもあれば「追記/置き換え」を選べます。テーマは足すだけ(PC で付けたものは消しません)。写真は1日1枚(PC に写真がある日は入れ替え。初期値はチェック OFF)。
  - タスク: PC のクイック追加と同じ書き方(#タグ @カテゴリ !高 明日 金曜 …)が使えます。「明日」は **スマホで書いた日** から数えます。
    「カテゴリ」でカンバンの列を選ぶと、その列に入ります(「おまかせ」なら文中の @カテゴリ → PC の確認画面の追加先)。
  - メモ: 追記先のメモを選んで書くと、PC のメモアプリがそのメモの末尾に「— スマホから 日時 —」の区切りつきで足します。
    追記先のメモが消えていたら、同じタイトルの新しいメモになります。
- 「今日」タブの予定・やること、「睡眠」タブの最近の睡眠は、ランチャーを起動したときに PC が書き出したものです。読めた内容は iPhone にしまうので、電波が無いときも前回の分を表示します。
  - 書き出すのは、今日から7日分の予定・期限の近い(または優先度「高」の)未完了タスク・直近7日の睡眠の数字、
    それにカンバンの列の名前とメモのタイトルの一覧(追加先・追記先を選ぶため)だけです。日記の本文・気分・メモの本文・吐き出しは書き出しません。

## セットアップ(はじめの一回だけ)

### 1. GitHub Pages に置く(アプリの置き場所)

1. GitHub のアカウントを作る(持っていれば不要)。
2. 新しいリポジトリを **Public** で作る。名前は例えば `diarium-pocket`。
3. 「Add file → Upload files」で、このフォルダの次のファイルをそのままアップロードする:
   `index.html` `app.js` `core.js` `auth.js` `config.js` `sw.js` `manifest.webmanifest` `icons/`(フォルダごと)
4. リポジトリの「Settings → Pages」で、Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして保存。
5. 数分で `https://<ユーザー名>.github.io/diarium-pocket/` が開けるようになる。**この URL を控えておく**(最後の `/` まで)。

> 置くのはプログラムだけで、日記のデータは一切置きません。

### 2. Microsoft Entra にアプリを登録する(OneDrive に書く許可をもらう)

1. 個人の Microsoft アカウントで <https://entra.microsoft.com> を開く(Azure の無料アカウント作成を求められたら、案内に従う)。
2. 「アプリの登録 → 新規登録」:
   - 名前: **`Diarium Pocket`**(この名前が OneDrive のフォルダ名になり、PC 側はこの名前のフォルダを探します。変えないでください)
   - サポートされているアカウントの種類: **「個人用 Microsoft アカウントのみ」**
   - リダイレクト URI: プラットフォームは **「シングルページ アプリケーション (SPA)」**、URI は手順 1 で控えた URL
3. 登録後の画面の **「アプリケーション (クライアント) ID」** をコピーする。
4. `config.js` の `clientId: ""` の `""` の中に貼り付けて保存し、GitHub にもう一度アップロードする(上書き)。

> クライアント ID は秘密の値ではありません(公開して大丈夫です)。パスワードやシークレットは作りません。
> 学校のアカウント(keio.jp)では、管理者の設定で登録や許可ができないことが多いので、個人用アカウントで行ってください。

### 3. iPhone に入れる

1. Safari で手順 1 の URL を開く。
2. 共有ボタン → **「ホーム画面に追加」**。以後はホーム画面のアイコンから開く(こうしないと、しばらく使わないと端末内の保存が消えることがあります)。
3. 「送る」タブ → 「Microsoft でサインイン」→ 許可する。
4. 何か1件書いて送ると、PC の OneDrive に `アプリ/Diarium Pocket/inbox` ができます。日記アプリの「設定 → スマホから」で ✓ が付けば準備完了です。

## ふだんの使い方

- **今日**: やることを1行で書いて「追加して送る」。期限は「今日/明日/日付を選ぶ」でも付けられます。下に今日の予定・やること・これからの予定が出ます(「更新」で PC の最新分を読み直し)。
- **日記**: 気分・テーマ・本文、必要なら写真を1枚。書きかけ(写真も)は自動で iPhone に残ります。
- **メモ**: 追記先のメモを選んで書き、「追記して送る」。書きかけは自動で iPhone に残ります。
- **睡眠**: 寝た/起きた時刻。下に直近7日の睡眠(目標より短い日はオレンジ)と、今夜の目安の就寝時刻。

- 書いて「保存して送る」。サインイン中で電波があれば、その場で OneDrive に送ります。電波がなければ「未送信」にたまり、次に開いたときに送ります。
- サインインは Microsoft の仕様で **24 時間ごと** に切れます。切れていたら、「送る」を押したときにサインイン画面を一度通ります(ログイン済みならアカウントを選ぶだけ)。
- PC で日記アプリを開くと、届いた記録の確認画面が出ます。「あとで」を押せば何もせずに閉じます(設定画面の「届いた記録を確認」からいつでも開けます)。

## クライアント ID を設定する前でも使える方法

「送る」タブの **「共有シートで『ファイルに保存』する」** → 「"ファイル"に保存」→ OneDrive → `for_me_read` → `inbox` フォルダ(無ければ作る)に保存。
PC の日記アプリ・カンバン・メモアプリは `for_me_read/inbox` も見に行きます(タスクはカンバン、メモへの追記はメモアプリ、それ以外は日記が取り込みます)。保存できたら「OK」を押すと、端末から本文を消します。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 画面と見た目 |
| `app.js` | 画面の動き(未送信の管理・送信) |
| `core.js` | 記録ファイルの形・入力チェック・睡眠時間の計算・日記のテーマ一覧(PC 側と同じルール) |
| `auth.js` | Microsoft サインイン(PKCE)と OneDrive への書き込み(inbox/・tasks/・memos/)・読み込み(outbox/) |
| `config.js` | クライアント ID |
| `sw.js` | オフラインでも開けるようにする |

PC 側は `diary/phone_inbox.py`(取り込みのロジック)と、`diary/diary_extensions.py` の確認画面。
検証: `python diary/verify_phone_inbox_20260929.py`(Node があれば core.js が作るファイルを PC 側が読めることも確かめます)。
手元で画面を試すとき: `python -m http.server 8765 --directory diarium_pocket` → <http://localhost:8765/>。

アプリを更新したら、`sw.js` の `CACHE` と `app.js` の `APP_VERSION` の日付を変えてからアップロードしてください。
iPhone 側は、次に開いたときに新しい版を裏で受け取り、受け取り終わると自動で1回読み直して切り替わります
(画面と中身が必ず同じ版になるよう、全ファイルをまとめて入れ替えます)。

PC 側の取り込み・書き出し:
- 勉強時間: `schedule/destinate_app/study_core.py` の `import_phone`(予定表アプリ・ランチャーが呼ぶ。検証 `schedule/verify_study_core.py`)
- 日記: `diary/phone_inbox.py`(検証 `diary/verify_phone_inbox_20260929.py`)
- メモ: `memo/memo_app/phone_memos.py`・`phone_memos_dialog.py`(検証 `memo/verify_phone_memos_20260930.py`)
- カンバン: `kanban/kanban/phone_tasks.py`・`phone_tasks_dialog.py`(検証 `kanban/verify_phone_tasks_20260929.py`)
- 書き出し: `launcher/mobile_export/pocket_outbox.py`(検証 `launcher/verify_pocket_outbox_20260929.py`)
